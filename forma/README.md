# Форма

Личный трекер зала, еды и добавок. Приложение для iPhone (PWA): ставится на главный экран, работает без интернета, данные хранятся на телефоне.

**Адрес:** https://hvg8yph4d7-ops.github.io/-my-skills/

## Как поставить на iPhone

1. Открой адрес выше в **Safari** (именно Safari, не Telegram и не Chrome).
2. Нажми «Поделиться» (квадрат со стрелкой вверх) → «На экран „Домой“» → «Добавить».
3. Запускай «Форму» с иконки. Так iPhone не удалит данные, даже если долго не открывать.

Важно: у иконки на главном экране и у Safari **разные хранилища**. Пользуйся всегда иконкой.

## Как записывать

Внизу любой вкладки — строка «Что ел / что делал…». Пиши как в чат («250 г курицы и пачка макарон, жим 70 на 5, вес 68,6») или сфотографируй этикетку (📷). Claude покажет, что понял, — поправь граммы или сними лишнее и нажми «Сохранить». Вечером в календаре нажми «Закрыть день» — Claude напишет вывод дня.

Для этого нужен ключ ИИ (⚙ → «ИИ для записей»). Бесплатно — Google Gemini: ключ на aistudio.google.com, **из России работает только с включённым VPN**. Платно — Claude (console.anthropic.com). Ключ хранится только на телефоне.

## Резервная копия

⚙ в правом верхнем углу → «Скачать копию» → «Сохранить в Файлы» (или отправь себе в Telegram).
Восстановить: ⚙ → «Загрузить из файла».

## Как обновлять

Ничего делать не нужно: после изменений в коде сайт сам пересобирается (вкладка **Actions** на GitHub), а приложение на телефоне подтягивает новую версию при следующем запуске. Иногда нужно закрыть и открыть его два раза.

## Для разработки

```bash
cd forma
npm install
npm run dev      # локальный сервер для разработки
npm run build    # сборка в папку dist
```
