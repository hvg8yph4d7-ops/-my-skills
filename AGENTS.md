# Правила для ИИ-агентов (Codex, ChatGPT и др.) в этом репозитории

В репозитории три независимых проекта:
- `forma/` — приложение «Форма» (трекер еды, зала и добавок Давида). **Основной проект.**
- `woodnext/`, `poker/` — другие сайты. Не трогай их, если об этом прямо не просили.

## «Форма» — перед любой правкой
1. Прочитай `forma/CLAUDE.md` целиком: там ТЗ, правила подсчёта КБЖУ и подробная история («Состояние проекта»).
2. Пользователь — Давид, новичок в программировании. Пишет по-русски с телефона. Отвечай по-русски, коротко, по шагам.

## Как вносить изменения
- Код — в `forma/src/` (React + TypeScript + Vite, PWA). Данные — на телефоне в IndexedDB (`forma/src/storage.ts`) и в Supabase (`forma/src/lib/cloud.ts`).
- Меняй как можно меньше и пиши в том же стиле, что окружающий код.
- **Не теряй старые данные.** При смене формата дневника добавь шаг в `migrate()` в `forma/src/storage.ts`.
- **Цвета и дизайн не меняй**, если об этом не просили.
- Разовые записи «за пользователя» — в `forma/src/lib/patches.ts`. Перед такой записью проверь `skip`: дубль ищи по основе слова и граммам.
- **Проверка перед коммитом** (из папки `forma/`): `npm ci`, затем `npx tsc --noEmit -p .`, затем `npm run build`. Всё должно пройти без ошибок.
- После заметной правки допиши абзац в раздел «9. Состояние проекта» в `forma/CLAUDE.md`: дата, что и зачем.

## Публикация
- Любой коммит в `main`, который меняет `forma/**`, публикует сайт https://hvg8yph4d7-ops.github.io/-my-skills/ через `.github/workflows/deploy-forma.yml` (1–3 минуты).
- Если публикация зависла или отменилась: Actions → Deploy Forma → Run workflow (main).
- На iPhone после обновления нужно закрыть «Форму» и открыть заново два раза.

## Безопасность
- Никаких ключей и паролей в коде, коммитах и чате: ни ключа Gemini или Claude, ни секретного ключа Supabase, ни токена сна. Публичный ключ Supabase (`sb_publishable_…`) и адрес проекта в `forma/src/config.ts` — можно, они публичные.
- Не удаляй данные пользователя и не меняй SQL в Supabase без явной просьбы. SQL пользователь запускает сам в Supabase → SQL Editor.
