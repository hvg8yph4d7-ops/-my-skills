# «Третий стук» — рабочий план для ежедневных роликов

Аккаунт со страшными историями (Instagram @tretiy_stuk7 + VK Клипы), владелец пишет с iPhone, коротко, без терминов.
Полный контент-план (документ): https://claude.ai/code/artifact/e64b98ea-72a5-4246-85a0-212c774852ec

## Каждое утро (запуск ~5:50 по Екатеринбургу, ролик к 7:00)

1. Открыть `docs/tretiy-stuk/STATUS.md` — что уже сделано, и календарь ниже — что сегодня.
2. Написать сценарий: 12–16 фраз, 45–60 с. Формула: крючок за 2 с → одна странность → нарастание → обрыв → «Часть N+1 — завтра утром».
   Для сериала — строго по «Библии» ниже, продолжать ровно с места прошлой серии (первая фраза: «В прошлой серии…» — коротко).
3. Озвучка: `tts/jobs/<id>.json` (голос ru-RU-DmitryNeural, rate "-4%", pitch "-12Hz", "tempo": 1.25 — ускорение при импорте, паузы срезаются (как у референса ~2,6 слова/с)), закоммитить и запушить —
   GitHub Actions «TTS voice» сам озвучит и закоммитит `tts/out/<id>/NN.mp3` (коммит «Озвучка готова»). Ждать `git fetch`.
   Фразы размером < 6 КБ — брак: удалить файл и перезапушить.
4. `cd woodnext-video && node tools/stuk-voice.mjs <id>` — тайминги в `src/stuk/timing/<id>.json`.
5. Сцены: `src/stuk/<id>.tsx` по образцу `s1e01.tsx` (набор в `kit.tsx`), зарегистрировать в `src/Root.tsx`.
   Проверить кадры (`remotion still`), потом рендер и пережатие для iPhone:
   `npx remotion render <ID> out/<id>-raw.mp4 --browser-executable=/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell`
   `ffmpeg -i out/<id>-raw.mp4 -c:v libx264 -profile:v high -level 4.0 -pix_fmt yuv420p -crf 23 -maxrate 4M -bufsize 8M -af loudnorm=I=-14 -c:a aac -b:a 160k -movflags +faststart out/tretiy-stuk-<id>.mp4`
6. Добавить серию на страницу роликов https://claude.ai/artifact/WiQPGAkjQenHnbjvx9wraS (владелец смотрит там,
   без скачивания): новый блок <section> сверху в `docs/tretiy-stuk/page/index.html`, видео для страницы — 720p
   (`-vf scale=720:-2 -crf 25 -maxrate 1.8M`, < 15 МБ) + постер jpg; публиковать Artifact с `url` этой страницы,
   `file_path` = docs/tretiy-stuk/page/index.html и `files` только с новыми v/<id>.mp4 и v/<id>.jpg (старые сохраняются).
7. Обложка серии: композиция `Cover` в `src/stuk/Cover.tsx` (ЧАСТЬ N + 2–3 слова, последнее красным; текст в полосе 240–1680),
   jpg в `docs/tretiy-stuk/brand/oblozhka-chast-N.jpg`.
   Прислать владельцу ссылку на страницу, ролик и обложку (SendUserFile) + готовую подпись для Instagram и VK + идею опроса для сторис.
8. Закоммитить исходники, озвучку, обновить STATUS.md, запушить.

Правила: никаких реальных имён живых людей и реальных адресов; без крови и насилия в кадре; в «Загадках» — только
проверенные факты (искать источники). Подпись всегда с «История вымышлена» для сериала и «Правил».

## Схема серии (по референсам surv_protocol, части 3–5: 46K / 24K / 17K лайков)

1. Удар с первой секунды — конкретика и цифра: «Свет погас ровно тогда, когда я поднял телефон», «9 ударов в дверь».
2. Ставки: что враг уже знает, сколько времени/расстояния («До рассвета 9 часов. До трассы 7 км»).
3. Вывод-правило: «Значит, ночь нужно провести с умом».
4. «Первое — … Второе — … Третье — …»: каждая хитрость выживания конкретная, бытовая, с цифрой;
   на полоске-«скотч» — номер и слово («1. СВЕТ»), плашки копятся на экране (Pills), вывод-максима («Свет = приглашение»).
5. Фирменная фраза: «На бумаге я был готов ко всему. Была лишь одна проблема.» → жёсткий поворот за 2–3 фразы.
6. Финал: «Часть N. <вопрос>?» + карточка «ТРЕТИЙ СТУК» с тремя ударами.
Длина 45–60 с (по статистике досматривают ~28 с — короче лучше), 15–20 фраз, голос tempo 1.25 без пауз, сверху отметка времени (stamp) «НОЧЬ 4 · 01:12».
«Правила» и «Загадки» — по той же схеме (удар → ставки → 3 пункта → поворот/вопрос).
