# Сайт-предзапись WOODNEXT: как всё устроено

Сайт, заявки и админка живут в одном месте — на бесплатном хостинге **Netlify**.
Гость записывается на сайте → заявка сохраняется на сервере Netlify → сразу видна в админке.
Никаких Google-таблиц и сторонних форм.

## Запуск (один раз, ≈3 минуты)

1. Откройте **app.netlify.com** → **Sign up** → **«Sign up with GitHub»** → разрешите доступ.
   (Аккаунт GitHub тот же, где лежит сайт.)
2. **Add new project → Import an existing project → GitHub.**
   Если GitHub спросит, к каким репозиториям дать доступ, выберите **-my-skills**.
3. Выберите репозиторий **-my-skills**. Все настройки уже прописаны в файле `netlify.toml`,
   ничего не меняйте — просто нажмите **Deploy**.
4. Через минуту появится адрес вида `https://какое-то-имя.netlify.app`.
   Поменять имя: **Project configuration → Change project name** → например `woodnext-den`.
5. Пришлите адрес Claude — он пропишет его в превью ссылки и перенаправит старую ссылку на GitHub на новый сайт.

Дальше сайт обновляется сам после каждого изменения в репозитории.

## Админка

Вход по паролю администратора (его сообщил Claude). Сменить пароль: в Netlify
**Project configuration → Environment variables → Add a variable**: имя `ADMIN_PASSWORD`, значение — новый пароль,
затем **Deploys → Trigger deploy**.

Что в админке:
- сколько **гостей** и **заявок** записано, сколько заявок за сегодня, сколько гостей уже **пришло**;
- разбивка «Откуда узнали»;
- список гостей с поиском; нажатие на телефон — звонок;
- **«Пришёл?»** — отмечать гостей на входе 8 ноября; фильтры «Ждём» / «Пришли» — для входа и розыгрыша;
- **«Удалить»** — например, тестовые заявки;
- **«Скачать список»** — файл для Excel;
- обновляется сама каждые 30 секунд.

Повторная заявка с того же номера показывается бледной с пометкой «повтор номера» и в итог не входит.

## Уведомления в Telegram (по желанию)

1. В Telegram: **@BotFather** → `/newbot` → придумайте имя → получите **токен**.
2. Добавьте бота в чат организаторов и напишите там `/start@имя_бота`.
3. Узнайте id чата: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100…`.
4. В Netlify → **Environment variables** добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, затем **Trigger deploy**.

После этого каждая заявка будет приходить в чат с итогом «Всего записано: N человек (M заявок)».

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html`, `styles.css`, `script.js` | сайт |
| `config.js` | адрес, телефон, соцсети, реквизиты компании |
| `admin.html` | админка |
| `privacy.html` | политика обработки персональных данных |
| `netlify/functions/` | сервер: приём заявок (`signup`) и админка (`admin`) |
| `netlify/lib/leads.mjs` | проверка и хранение заявок |
| `images/` | логотип и фото (заменить — положить файл с тем же именем) |
| `og-image.jpg` | картинка превью ссылки в мессенджерах |

## Что ещё заполнить в config.js

Ссылку на канал Max, юр. название, ИНН, юридический адрес и e-mail компании — они нужны для страницы политики.

## Про персональные данные

Netlify — зарубежный хостинг, это трансграничная передача данных (политика это описывает).
Покажите политику юристу; при строгих требованиях к локализации заявки можно перенести на российский сервис.
