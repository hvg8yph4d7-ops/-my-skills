# Сайт-предзапись WOODNEXT: инструкция по запуску

Всё бесплатно: сайт — на GitHub Pages (или Netlify/Vercel), заявки — в Google Таблицу, уведомления — в Telegram.
Займёт около 30–40 минут. Делайте шаги по порядку.

## Ссылки

| | Адрес |
|---|---|
| **Сайт для гостей** | https://hvg8yph4d7-ops.github.io/-my-skills/woodnext/ |
| **Админка (только организаторам)** | https://hvg8yph4d7-ops.github.io/-my-skills/woodnext/admin.html |

Сайт обновляется сам через 1–2 минуты после каждого изменения в ветке `main` репозитория `-my-skills`.
Править файлы можно прямо на github.com: открыть файл → значок карандаша ✏️ → изменить → **Commit changes**.
Пока не выполнены шаги 1–2, форма на сайте пишет «Форма ещё не подключена», а в админке доступно только демо.

## Что лежит в папке

| Файл | Что это |
|---|---|
| `index.html` | сама страница |
| `privacy.html` | политика обработки персональных данных |
| `admin.html` | админка: список гостей, итоги, отметка «пришёл», выгрузка в Excel |
| `config.js` | **все настройки**: ссылка на скрипт, адрес, телефон, соцсети, реквизиты компании |
| `styles.css`, `script.js` | оформление и логика (трогать не нужно) |
| `apps-script/Code.gs` | код для Google Таблицы и Telegram |
| `images/` | сюда кладутся логотип и фото |
| `og-image.jpg` | картинка превью ссылки в мессенджерах (1200×630) |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | иконки сайта |
| `_source/og-image.html` | исходник картинки превью (на всякий случай) |

## Шаг 0. Заполните config.js

Откройте `config.js` в любом текстовом редакторе (Блокнот, TextEdit, VS Code) и замените всё, что в `[квадратных скобках]`:
адрес производства, телефон, ссылку на канал Max, юр. название, ИНН, адрес и e-mail компании.
Кавычки `'...'` и запятые в конце строк оставляйте как есть.

- Telegram и VK оставьте пустыми `''`, если их нет — кнопки просто не появятся.
- `MAP_URL` — точная точка на карте. Откройте Яндекс Карты, найдите производство, нажмите **«Поделиться» → «Скопировать ссылку»** и вставьте. Если оставить пустым, карта откроется поиском по адресу.
- `PHONE_TEL` — номер для набора одним нажатием, только цифры с `+`: `'+73439123456'`.

`SCRIPT_URL` заполните на шаге 1.

## Шаг 1. Google Таблица и Apps Script

1. Зайдите на [sheets.google.com](https://sheets.google.com) под Google-аккаунтом компании → **«Пустой файл»**. Назовите таблицу, например «WOODNEXT — День открытых дверей».
2. В меню таблицы: **Расширения → Apps Script**. Откроется редактор кода.
3. Удалите всё, что там написано (`function myFunction() {}`), и вставьте **целиком** содержимое файла `apps-script/Code.gs`.
4. Нажмите значок дискеты **«Сохранить»** (или Ctrl+S).
5. Сверху в выпадающем списке функций выберите **`setup`** и нажмите **«Выполнить»**.
   - Google попросит доступ: **«Проверить разрешения»** → выберите свой аккаунт.
   - Появится «Google не проверял это приложение» — это нормально, скрипт ваш. Нажмите **«Дополнительно» → «Перейти на страницу … (небезопасно)» → «Разрешить»**.
   - Вернитесь в таблицу — появятся листы **«Заявки»** и **«Итого»** с формулами.
6. Опубликуйте скрипт: в редакторе справа сверху **«Начать развертывание» → «Новое развертывание»**.
   - Нажмите шестерёнку рядом с «Выберите тип» → **«Веб-приложение»**.
   - Описание: любое, например «Заявки».
   - **Запуск от имени: «Я»**.
   - **У кого есть доступ: «Все»** (именно «Все», не «Все с аккаунтом Google»).
   - **«Начать развертывание»** → снова разрешите доступ, если попросит.
7. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`.
8. Вставьте его в `config.js`:
   ```js
   SCRIPT_URL: 'https://script.google.com/macros/s/AKfy...../exec',
   ```
9. Проверка: откройте эту ссылку в браузере — должно появиться слово **ok**.

> ⚠️ **Важно:** если вы меняете код скрипта (например, вписываете токен бота на шаге 2), изменения начнут работать
> только после **«Начать развертывание» → «Управление развертываниями» → карандаш ✏️ → Версия: «Новая версия» → «Развернуть»**.
> Ссылка `/exec` при этом не меняется.

**Что в таблице.** Лист «Заявки»: дата и время, имя, телефон, сколько человек, источник, отметка «Повтор номера» и технический ID.
Если один и тот же телефон записался второй раз, строка всё равно добавится, но с пометкой «да» — в итог она не входит, чтобы гости не задвоились.
Лист «Итого»: количество заявок, общее количество гостей и разбивка по источникам (заявки и гости).

## Шаг 2. Telegram-бот для организаторов

1. В Telegram найдите **@BotFather** → **Start** → отправьте `/newbot`.
2. Придумайте имя бота (например, «WOODNEXT Заявки») и username, который заканчивается на `bot` (например, `woodnext_dod_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAHk...`. Никому его не показывайте.
4. Создайте группу организаторов (или используйте существующую) и **добавьте туда бота** как участника.
5. Напишите в группе команду с именем бота, например: `/start@woodnext_dod_bot` (обычные сообщения бот в группе не видит, команды — видит).
   Если уведомления нужны только вам лично — просто откройте чат с ботом и нажмите **Start**.
6. В Apps Script вверху файла вставьте токен:
   ```js
   var TELEGRAM_BOT_TOKEN = '1234567890:AAHk...';
   ```
   Сохраните, выберите функцию **`findChatId`** → **«Выполнить»**. Внизу в «Журнале выполнения» появится строка вроде
   `chat_id: -1001234567890 — Организаторы ДОД (supergroup)`.
   (Для группы chat_id начинается с минуса — минус обязательно копируйте.)
7. Вставьте его:
   ```js
   var TELEGRAM_CHAT_ID = '-1001234567890';
   ```
   И сразу придумайте пароль для админки (длинный, не меньше 10 символов):
   ```js
   var ADMIN_PASSWORD = 'придумайте-свой-пароль';
   ```
8. Сохраните, выберите функцию **`testTelegram`** → **«Выполнить»**. В чат придёт «✅ Бот WOODNEXT подключён».
9. **Выпустите новую версию** развертывания (см. «Важно» в шаге 1) — иначе сайт будет работать со старым кодом без токена.

Токен хранится только в скрипте Google — на сайте его не видно. Счётчик записавшихся видят только организаторы в Telegram и в таблице.

## Шаг 3. Публикация сайта

**Сайт уже опубликован на GitHub Pages** (ссылки — в начале файла), этот шаг можно пропустить.
Варианты ниже — если захотите свой отдельный адрес на Netlify или Vercel.

### Вариант А — Netlify (проще всего, без GitHub)

1. Зарегистрируйтесь на [netlify.com](https://app.netlify.com/signup) (можно через Google-аккаунт). Бесплатного тарифа хватит с запасом.
2. **Sites → Add new site → Deploy manually.**
3. Перетащите в окно **всю папку `woodnext`** целиком (не отдельные файлы).
4. Через несколько секунд появится ссылка вида `https://random-name-123.netlify.app`.
5. Переименуйте: **Site configuration → Change site name** → например `woodnext-den` → ссылка станет `https://woodnext-den.netlify.app`.
6. Чтобы обновить сайт после правок: **Deploys** → снова перетащите папку `woodnext` в зону «Drag and drop».

### Вариант Б — Vercel (через GitHub, обновляется сам)

1. Зарегистрируйтесь на [vercel.com](https://vercel.com/signup) через GitHub.
2. **Add New → Project** → выберите репозиторий `-my-skills` → **Import**.
3. **Root Directory → Edit → `woodnext`**. Framework Preset: **Other**. Остальное не трогайте → **Deploy**.
4. Получите ссылку вида `https://woodnext-den.vercel.app` (имя проекта можно сменить в **Settings → General**).
5. Дальше каждое изменение в ветке `main` сайт подхватит сам.

### Если переезжаете на Netlify/Vercel — поправьте превью

Мессенджерам нужен полный адрес картинки. Откройте `index.html`, найдите **`https://hvg8yph4d7-ops.github.io/-my-skills/woodnext/`** (2 места в начале файла:
`og:url` и `og:image`) и замените на новый адрес, например `https://woodnext-den.netlify.app/`. Опубликуйте ещё раз.

Проверить превью: отправьте ссылку себе в «Избранное» в Telegram. Если превью старое или пустое — отправьте ссылку боту
**@WebpageBot** в Telegram, он обновит кэш. WhatsApp и Max кэшируют превью сами, иногда обновление занимает до суток —
поэтому проверьте превью **до** массовой рассылки.

## Админка

Ссылка: https://hvg8yph4d7-ops.github.io/-my-skills/woodnext/admin.html — на сайте для гостей её нет, отправляйте только организаторам.
Вход по паролю `ADMIN_PASSWORD` из Apps Script. Пароль проверяет Google, а не сайт, поэтому без него данные не получить.
После 10 неверных попыток вход блокируется на 10 минут.

Что в ней:
- сколько **гостей** и **заявок** записано, сколько заявок пришло сегодня, сколько гостей уже **пришло**;
- разбивка «Откуда узнали»;
- список гостей с поиском по имени и телефону; нажатие на телефон — звонок;
- кнопка **«Пришёл?»** — отмечайте гостей на входе 8 ноября, отметка сразу пишется в таблицу (колонка «Пришёл»). Фильтры «Ждём» и «Пришли» помогут на входе и при розыгрыше;
- **«Скачать список»** — CSV, открывается в Excel;
- список обновляется сам каждые 30 секунд;
- «Запомнить на этом устройстве» — чтобы не вводить пароль каждый раз (не ставьте галочку на чужом телефоне).

Пока не подключён Apps Script, в админке есть кнопка **«Посмотреть демо»** с вымышленными заявками.

> Пароль и токен бота меняются в Apps Script — после изменения выпустите **новую версию** развертывания (см. шаг 1).

## Шаг 4. Тестовая заявка

1. Откройте сайт **с телефона** (и для проверки — в Telegram/Max, во встроенном браузере).
2. Заполните форму: имя «Тест», ваш телефон, 2 человека, источник «Telegram» → **«Записаться»**.
3. Проверьте:
   - на сайте появился экран **«Спасибо, вы записаны! Ждём вас 8 ноября в 12:00»**;
   - кнопка **«Добавить в календарь»** скачивает файл и предлагает добавить событие;
   - в таблице на листе «Заявки» появилась строка, на листе «Итого» — 1 заявка и 2 гостя;
   - в Telegram пришло сообщение с данными и строкой «Всего записано: 2 человека (1 заявка)»;
   - в админке видна заявка, кнопка «Пришёл?» ставит «да» в колонке «Пришёл» таблицы.
4. Дважды быстро нажмите «Записаться» — заявка должна прийти только одна.
5. После проверки **удалите тестовые строки** из листа «Заявки» (правый клик по номеру строки → «Удалить строку»).

Если что-то не работает:

| Симптом | Что проверить |
|---|---|
| На сайте «Форма ещё не подключена» | не заполнен `SCRIPT_URL` в `config.js` или сайт не переопубликован |
| «Не удалось отправить» | в развертывании доступ «Все»; ссылка заканчивается на `/exec`; открыв её в браузере, видно «ok» |
| Строка в таблице есть, Telegram молчит | токен и chat_id вписаны; выпущена **новая версия** развертывания; бот добавлен в группу; запустите `testTelegram` |
| После заявки на этом телефоне сразу показывается «Спасибо» | так задумано: сайт помнит, что вы уже записались. Нажмите «Записать ещё одного гостя» |

Ошибки скрипта видны в Apps Script → слева **«Выполнения»**.

## Шаг 5. Логотип и фото

**Логотип** уже стоит: `images/logo.png` (белый на прозрачном фоне, 900×187). Чтобы сменить — замените этот файл,
сохранив имя. Он же используется на картинке превью (`_source/og-image.html`).

**Фото** уже стоят. Чтобы заменить — положите новый файл с тем же именем:

| Файл | Где на сайте | Формат |
|---|---|---|
| `images/house-3.jpg` | первый экран на телефоне | вертикальное, ~1000×1330 |
| `images/house-1.jpg` | первый экран на компьютере, галерея, картинка превью | горизонтальное, ~1600×870 |
| `images/house-2.jpg` | галерея | горизонтальное, ~1200×900 |
| `images/production.jpg` | галерея, «Фото производства» — **появится само**, когда файл будет в папке | горизонтальное, ~1600×1000 |

Перед загрузкой сожмите фото до 300–400 КБ на [squoosh.app](https://squoosh.app) — так страница быстро откроется по мобильному интернету.
Имена — латиницей, маленькими буквами, расширение `.jpg` (не `.JPG` и не `.jpeg`).

**Картинка превью** `og-image.jpg` уже готова. Если захотите свою — сделайте JPG 1200×630 до 300 КБ с тем же именем.

После замены файлов опубликуйте сайт заново (Netlify — перетащить папку, Vercel — сохранить изменения в GitHub).

## Про персональные данные (важно прочитать)

- Заполните реквизиты оператора в `config.js` — они подставятся в `privacy.html`.
- По 152-ФЗ первичный сбор данных граждан РФ должен вестись в базах на территории России, а Google Таблицы и Telegram хранят данные за рубежом
  (это трансграничная передача, о ней нужно уведомить Роскомнадзор). Политика это честно описывает, но для полной уверенности покажите её
  юристу. Если нужна строгая локализация — заявки можно принимать в Яндекс Формы, это тоже бесплатно.
- С 1 сентября 2025 года согласие на обработку должно быть оформлено отдельно от других документов. На странице политики оно вынесено
  отдельным разделом «Согласие на обработку персональных данных»; при желании юрист может попросить заменить фразу под кнопкой на галочку.
