# Покерная лига — как запустить

Сайт: https://hvg8yph4d7-ops.github.io/-my-skills/poker/
Демо с выдуманными игроками (ничего не сохраняет на сервер): https://hvg8yph4d7-ops.github.io/-my-skills/poker/?demo

## Один раз: база данных (5 минут)

Лига живёт в той же базе Supabase, что и «Форма», в отдельных таблицах `poker_*`.

1. Откройте [supabase.com](https://supabase.com) → проект «Формы» → **SQL Editor** → **New query**.
2. Откройте файл [`supabase.sql`](supabase.sql), скопируйте его целиком и вставьте.
3. **В самом конце файла** замените `79990000000` на свой номер (в формате 7XXXXXXXXXX) и, если нужно, имя `Давид`.
4. Нажмите **Run**. Должно появиться «Success».

Повторный запуск безопасен — ничего не сотрётся.

## Первый вход

1. Откройте сайт, введите свой номер и придумайте PIN из 4 цифр — это и есть регистрация.
2. Внизу появится вкладка **Админ**.

## Добавить друзей

Админ → **Игроки** → имя + номер телефона → «Добавить». Скиньте другу ссылку на сайт:
он входит по своему номеру и сам придумывает PIN. После входа сразу открывается его кабинет.

Забыл PIN — Админ → Игроки → «Изменить» → **Сбросить PIN**, и игрок задаст новый.
Галочка «Может записывать вечера» делает игрока вторым админом.

## Записать вечер

Админ → **Записать вечер**: нажимайте игроков по порядку мест (сначала победителя), укажите
ставку, кто собирал деньги, комментарий и фото последней раздачи → «Записать вечер».
Призы, рейтинг и достижения считаются сами. Ошибся — вкладка «Вечера» → «Исправить».

Можно вести игру и вживую: Админ → **Стол вживую** → «Вылетел» по ходу игры.

## Безопасность

- Сайт обращается к базе только через функции `poker_*`; таблицы снаружи не читаются.
- Номера телефонов видит только админ. PIN хранится в виде хэша.
- После 5 неверных PIN подряд вход по этому номеру закрывается на 15 минут.
- PIN из 4 цифр — защита «для своих», а не банковская. Ничего ценного, кроме рейтинга, там нет.
