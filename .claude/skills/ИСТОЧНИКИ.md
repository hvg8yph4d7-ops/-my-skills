# Скиллы для видео — откуда взяты

Все скиллы — открытые репозитории GitHub (скачаны 22.10.2026). Выбраны по каталогу
[zhuyansen/awesome-claude-video-skills](https://github.com/zhuyansen/awesome-claude-video-skills) и популярности.

| Папка | Источник | Что делает |
|---|---|---|
| `video-use` | [browser-use/video-use](https://github.com/browser-use/video-use) (MIT) | Монтаж сырых съёмок в разговоре: нарезка по словам, цвет, вставки, субтитры. **Доработан:** без ключа ElevenLabs распознаёт речь локальным Whisper (`helpers/asr_local.mjs`) |
| `brag`, `brag-slim` | [latent-spaces/brag](https://github.com/latent-spaces/brag) (MIT) | Промо-ролик из сайта/проекта с музыкой |
| `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `media-use`, `remotion-to-hyperframes`, `slideshow`, `figma` | [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) (~70k★) | Видео из HTML/CSS, готовые блоки-титры, слайдшоу |
| `make-short`, `make-ai-short`, `make-vox`, `suggest-sfx`, `vidtsx-2d-generator` | [hassancs91/claude-faceless-shorts-creator](https://github.com/hassancs91/claude-faceless-shorts-creator) | Фабрика faceless-шортсов: 2D-анимация на Remotion, озвучка, звуки. Нужен проект-заготовка из репозитория (клонировать при первом запуске) |
| `papercut-*` (9 шт.) | [0xS4N4TG/papercut-explainer](https://github.com/0xS4N4TG/papercut-explainer) | Вертикальные объясняющие ролики в стиле вырезанной бумаги: стратегия → хук → сценарий → раскадровка → сборка → проверка. Нужна библиотека Remotion из репозитория |
| `lemo-opuscar` | [lemomo-ai/lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) (~5k★) | 59 готовых стилей фильмов, сделанных кодом. Стили лежат в репозитории (клонировать при первом запуске) |
| `explainroo` | [vincentsch/explainroo](https://github.com/vincentsch/explainroo) | Быстрее всех в тесте каталога: от задачи до ролика со звуком за ~2 минуты |
| `reel-edit` | [tenfoldmarc/video-edit-skill](https://github.com/tenfoldmarc/video-edit-skill) | Из сырых «говорящих голов» — готовый премиальный Reels |
| `ffmpeg-edit` | [6missedcalls/video-editing-skill](https://github.com/6missedcalls/video-editing-skill) | Простой монтаж FFmpeg + Whisper: обрезка, jump-cut, субтитры в стиле Хормози, скорость |
| `remotion-ads` | [Maartenlouis/remotion-ads](https://github.com/Maartenlouis/remotion-ads) | Рекламные Reels и карусели для Instagram на Remotion |

Ограничения облачной среды: ElevenLabs, huggingface.co, соцсети закрыты — озвучку и распознавание
заменяем локальными средствами (см. `video-use/helpers/asr_local.mjs`).
